# Local destination photographs — required before visual acceptance

Network access to Wikimedia was unavailable in the implementation environment.
No photographs, generated pictures, or fake photo placeholders are included.
The adapter shows compact text recommendations and HOME explicitly discloses missing photographs.

Install independently licensed photographs at exactly these paths:

- areamap/hikes/tri_bratya.webp
- areamap/hikes/big_almaty_lake.webp
- areamap/hikes/butakovsky_waterfall.webp
- areamap/hikes/kok_zhailau.webp
- areamap/hikes/furmanov_peak.webp
- areamap/hikes/medeu_shymbulak.webp
- areamap/hikes/tourist_peak.webp

Use 540 × 660 px portrait crops, WebP quality around 80, ideally under 150 KB each.
No network image loading is used. Restart the rebuilt application after adding assets.
Retain a per-file author, source URL, license URL, and crop/resize notice in this directory.
Also expose applicable credits in the app before distributing a photo-bearing build.
Do not describe a photograph of another destination as the location on the card.

Verified candidates for two destinations:

- Big Almaty Lake: Igors Jefimovs, https://commons.wikimedia.org/wiki/File:Big_Almaty_Lake.jpg
  CC BY 3.0, https://creativecommons.org/licenses/by/3.0/
- Butakovsky waterfall: https://commons.wikimedia.org/wiki/File:Butakovka_Waterfall_-_panoramio.jpg
  Verify author and license on the source page before downloading.
